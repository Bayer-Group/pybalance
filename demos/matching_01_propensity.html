Propensity Score Matcher

In this notebook, we show the basic usage of the PropensityScoreMatcher. The propensity score (Rosenbaum & Rubin, 1983) is the probability of belonging to the target population given baseline covariates:

\begin{equation} e(x) = P(Z = 1 \mid X = x) \end{equation}

where \(X\) are the covariates and \(Z = 1\) indicates membership in the target. Patients are matched on similar estimated scores.

Unlike the GeneticMatcher and ConstraintSatisfactionMatcher, the PropensityScoreMatcher does not directly optimize a particular balance score. Instead, it uses the given objective as a measure of “correctness” of the propensity score model, tries a (possibly large) number of potential models, and returns the one with the best score. In doing this, we automate the often manual hyperparameter optimization that accompanies propensity score matching. Because balance is not optimized directly, residual imbalance often remains; see the linear program demo for how to improve upon a propensity score match.

Optimize Beta (Mean Absolute SMD)

Using the given objective function, search max_iter possible different propensity score models and take the model that gives the best match given that objective function.

[3]:

# Note that using a caliper can result in matched population being
# smaller than target! If this is undesired, do not use a caliper.
objective = beta = BetaBalance(m)
matcher = PropensityScoreMatcher(
    matching_data=m,
    objective=objective,
    time_limit=300,
    max_iter=100)
matcher.get_params()
